# Startpage Launcher

自分用のスマホホーム画面風スタートページです。よく使うリンクをフォルダごとに整理し、検索、追加、編集、削除、並び替え、バックアップをブラウザ内で完結できます。

公開URL: https://takumifr.github.io/startpage/

## 主な機能

- スマホのホーム画面風フォルダ表示
- フォルダ内リンク一覧表示
- リンク名、フォルダ、説明文による検索
- リンクの追加、編集、削除
- 長押しで入る編集モード
- 編集モード中のドラッグ並び替え
- `iconUrl`またはリンク先ドメイン由来のファビコン表示
- JSONによるインポート/エクスポート
- localStorage保存
- GitHub Pagesで動く静的サイト
- PWAとしてホーム画面に追加できる基本設定

## 使い方

1. 公開URLを開きます。
2. 検索欄からリンクを絞り込めます。
3. 「リンクを追加」から名前、URL、フォルダ、説明、アイコンを登録できます。
4. アイコンを約600ms長押しすると編集モードに入ります。
5. 編集モードでは、アイコンの削除、編集、ドラッグ並び替えができます。
6. 「エクスポート」でJSONバックアップを保存できます。
7. 「インポート」でJSONバックアップを復元できます。

## 開発方針

- HTML / CSS / JavaScriptのみで軽量に保つ
- 外部ライブラリを安易に追加しない
- スマホで毎日使う操作感を優先する
- 既存のlocalStorageデータ互換性をできるだけ壊さない
- 検索、追加、編集、削除、並び替え、インポート、エクスポート、PWAを壊さない
- 変更は小さめのPR単位にまとめる
